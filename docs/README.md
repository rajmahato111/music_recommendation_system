## 📊 Visualizations

The `visualizations/` directory contains interactive HTML visualizations generated by `generate_project_visualization.py`:

### Available Visualizations

1. **system_architecture.html** - System architecture diagram showing all layers
2. **data_flow.html** - Data flow diagram from raw data to recommendations
3. **metrics_dashboard.html** - Model performance metrics dashboard
4. **training_progress.html** - Training loss curves (placeholder)
5. **feature_importance.html** - Feature importance for ranking model
6. **confusion_matrix.html** - Confusion matrix heatmap
7. **roc_curve.html** - ROC curve for ranking model
8. **prediction_distribution.html** - Distribution of prediction scores
9. **technology_stack.html** - Technology stack visualization

### Viewing Visualizations

To view the visualizations:
1. Open any HTML file in a web browser
2. The charts are interactive - you can zoom, pan, and hover for details
3. All visualizations use Plotly for interactivity

### Regenerating Visualizations

To regenerate the visualizations with updated data:

```bash
python docs/generate_project_visualization.py
```

**Note:** The current visualizations use placeholder/sample data. Once you train your models and have actual metrics, you can update the `generate_project_visualization.py` script to use real data.

## 🔧 Updating with Real Metrics

To update the visualizations with actual metrics from your trained models:

1. **Update metrics_dashboard()** function in `generate_project_visualization.py`:
   ```python
   # Replace sample data with actual metrics
   metrics_data = {
       'Model': ['Baseline', 'Item2Vec', 'Hybrid', 'Hybrid+Ranking'],
       'Recall@5': [actual_recall_5_baseline, ...],
       # ... etc
   }
   ```

2. **Update training_progress()** function with actual training logs:
   ```python
   # Load from your training logs
   epochs = your_epochs
   train_loss = your_train_loss
   val_loss = your_val_loss
   ```

3. **Update feature_importance()** with actual feature importance from LightGBM:
   ```python
   # Get from trained ranking model
   model = your_trained_ranker.model
   importance = model.feature_importance()
   ```

4. **Update confusion_matrix()** with actual predictions:
   ```python
   # From your evaluation results
   cm = your_confusion_matrix
   ```
